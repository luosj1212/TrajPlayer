# Security Policy

## Supported Versions

Security fixes are applied to the newest published alpha or stable release.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security > Advisories > Report a vulnerability** flow to send a
private report to the maintainers.

Include the TrajPlayer version, operating system, affected file format, a
minimal reproduction when safe, and the expected impact. Do not attach private
or proprietary molecular trajectories; use a synthetic reproducer instead.
