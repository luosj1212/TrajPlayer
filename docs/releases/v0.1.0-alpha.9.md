# TrajPlayer v0.1.0-alpha.9

This prerelease focuses on native XYZ/extXYZ input, measured million-atom
camera-stop latency, and a more usable desktop interface. Molecular shading,
ball-and-stick proportions, antialiasing, and sequential no-skip playback keep
their existing behavior.

## Native Trajectory Input

- Common XYZ rows such as `C 1.2 2.3 3.4` and standard extXYZ
  `Properties=species:S:1:pos:R:3` layouts are parsed by `_trajcore` directly
  into a caller-owned contiguous `float32[N,3]` streaming slab.
- Unusual valid `Properties` layouts retain the existing Python fallback.
- The direct path removes both the per-atom Python decode/split/float loop and
  the temporary reader-to-slab full-frame copy.
- ASE `.traj`, XYZ/extXYZ, XTC, and TRR readers retain their metadata copy of
  frame 1 for first display instead of decoding that frame twice.

In a local Linux/WSL benchmark, one million standard XYZ atoms took about
105.6 ms in the native parser versus about 2319 ms in the previous Python path,
roughly 22x faster. Filesystem, compiler, and CPU results will vary.

## Million-Atom Rendering

- A five-second camera spin/stop mode now records depth ordering, CPU array
  rebuild, static GPU upload, and the complete first post-interaction frame as
  separate event-only metrics.
- The measured alpha.8 path produced an approximately 78 ms stop spike because
  depth-sorted color, radius, and periodic-anchor arrays were gathered,
  converted to bytes, and uploaded again.
- Alpha.9 keeps those atom attributes in canonical GPU texture buffers. A
  camera-dependent sort rebuilds and uploads only the atom permutation.
- On the same one-million-atom source benchmark, the stop event fell to roughly
  22-26 ms; the standalone native projected order was about 5.8 ms. Normal
  paint cadence and the rendered image were unchanged.

The existing three-buffer position upload ring remains in place. More invasive
map/fence upload strategies were not added because the measured 100,000-atom
position upload remains around 0.35 ms and did not justify the extra risk.

## Interface And Topology

- Controls now live in a responsive right-side inspector with Display,
  Selection, Playback, Advanced, and Interface sections.
- The transport bar is limited to the timeline and frequent playback commands;
  the inspector automatically folds away on narrow windows.
- Chinese and English UI text can be switched at runtime and is remembered.
- Candidate sorting and valence-cap bond selection now run in native code. A
  local one-million-candidate benchmark measured about 554 ms versus 2206 ms
  for the previous NumPy-sort/Python-loop path, with identical bonds.

## Packaging Validation

- Packaged native smoke tests now require all alpha.9 hot paths, including XYZ
  parsing, projected depth ordering, topology operations, and valence selection.
- A Linux `strip --strip-unneeded` A/B saved only 2.43 MB (1.26%) in the
  portable tree and about 0.21 MB in the compressed archive after excluding
  NumPy libraries that GNU strip damaged. The release therefore keeps
  `strip=False`.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.9.zip` from the assets below, not
the source archive under **Code > Download ZIP**. Extract the complete archive
and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required. Keep
`_internal` beside the executable and do not share the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.9.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and common Qt XCB runtime
libraries are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.9.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.9.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

Use **Open** or drag files into TrajPlayer. ASE `.traj`, `.xyz`, and `.extxyz`
open directly. GRO and XTC/TRR can be selected or dropped together; a
same-named GRO beside XTC/TRR is detected automatically. This remains an alpha
release, so keep original trajectories and report reproducible issues through
GitHub Issues.
