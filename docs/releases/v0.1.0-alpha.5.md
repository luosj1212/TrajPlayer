# TrajPlayer v0.1.0-alpha.5

This prerelease focuses on scientific clarity, cache hardening, background-I/O
reliability, and real graphics validation. Molecular rendering appearance and
sequential no-skip playback remain unchanged.

## Added

- The trajectory information line now identifies static bonds as inferred from
  frame 1, and **Infer bonds** can disable that inference.
- Chain isolation now accepts lists and ranges such as `1,3-5`. Each selected
  chain follows its own current-frame periodic anchor, so no atom is pinned
  while the trajectory plays.
- Native macOS 13+ app bundles are built separately for Apple Silicon and
  Intel. Finder file-open events are coalesced so GRO and XTC/TRR pairs can be
  opened together.
- A privacy-safe diagnostics command reports Python, dependencies, platform,
  writable log storage, and the actual OpenGL vendor, renderer, and version.
- CI and Release jobs create a real OpenGL context, open the included sample,
  validate a nonblank first frame, advance, and validate the second frame.

## Reliability

- Sidecar metadata is bounded and validated before mapping. Position, cell,
  atom-number, and frame-availability files must have exact expected sizes and
  cannot escape the cache directory.
- Streaming exceptions reach the UI. A store is not closed while a background
  reader still owns it, and application shutdown uses a bounded deadline.
- The render scheduler no longer wakes every 16 ms while idle; playback and
  ready-frame events schedule one-shot updates.
- Error logs rotate at 2 MiB and startup paths are redacted. The Open shortcut
  now uses Ctrl+O on Windows/Linux and Cmd+O on macOS.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.5.zip` from the assets below, not
the source archive under **Code > Download ZIP**. Extract the complete archive
and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required. Keep
`_internal` beside the executable; do not run the EXE inside the ZIP or share it
by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.5.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. The portable build requires Linux x86_64, OpenGL 3.3,
and common Qt XCB runtime libraries.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.5.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.5.zip` for an Intel Mac. Extract the ZIP
and open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required, and the app
may be moved to `/Applications` as a whole.

These alpha builds are ad-hoc signed but not Apple-notarized. On first launch,
Control-click `TrajPlayer.app`, choose **Open**, then confirm **Open**. macOS 13
or newer and OpenGL 3.3 are required.

## Opening Trajectories

Use **Open** or drag files into the application. ASE `.traj`, `.xyz`, and
`.extxyz` files open directly. For Gromacs, select or drag a GRO topology
together with its XTC/TRR trajectory. TrajPlayer can also try a same-named GRO
beside an XTC/TRR file when the trajectory is opened by itself.

To generate a diagnostics file for an issue, run the executable with
`--doctor-output=trajplayer-diagnostics.json`.

This is an alpha release. Cache metadata and file compatibility may change;
keep original trajectories and report reproducible failures through GitHub
Issues.
