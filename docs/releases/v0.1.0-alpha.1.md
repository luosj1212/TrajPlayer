# TrajPlayer v0.1.0-alpha.1

This is the first public technical preview of TrajPlayer, a GPU-first desktop
viewer for large local molecular trajectories.

## Included

- Portable Windows x64 and Linux x86_64 packages
- ASE `.traj`, XYZ/extXYZ, PDB, CIF, and GRO input
- Gromacs XTC/TRR trajectories paired with GRO topology
- Ball-stick, Ball, and Bond rendering
- Live random-access scrubbing, bounded background prefetch, and no-skip playback
- Periodic boxes and chain/atom isolation

## Install

Download the archive for your operating system, extract the complete
`TrajPlayer` directory, and keep `_internal` beside the executable.

This is an alpha release. Cache metadata and file compatibility may change;
keep original trajectories and report reproducible failures through GitHub
Issues.
