# TrajPlayer v0.1.0-alpha.12

This prerelease adds true vector export of the current molecular viewport. It
does not change molecular rendering, playback scheduling, trajectory loading,
or analysis behavior.

## Current-view SVG Export

- Open **View > Advanced > Export vector SVG** to export only the molecular
  viewport, without TrajPlayer controls or other application chrome.
- The SVG preserves the current camera, crop, representation, visible atoms
  and bonds, size controls, colors, selection highlighting, background, and
  visible periodic box.
- Atoms, two-tone bonds, gradients, and box edges remain editable vector
  primitives; no screenshot is embedded in the file.
- Export encoding and file I/O run in a cancellable background worker so the
  UI and OpenGL viewport stay responsive.

For an exact pixel copy, continue to use **Save screenshot**. SVG lighting is a
vector approximation of the OpenGL shader, while scene geometry and projection
follow the current viewport.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.12.zip` from the assets below,
not the source archive under **Code > Download ZIP**. Extract the complete
archive and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required.
Keep `_internal` beside the executable; do not send the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.12.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and the common Qt XCB runtime
libraries listed in the README are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.12.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.12.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

Use **Open** or drag files into TrajPlayer. ASE `.traj`, `.xyz`, and `.extxyz`
open directly. GRO and XTC/TRR can be selected or dropped together; a
same-named GRO beside XTC/TRR is detected automatically.
