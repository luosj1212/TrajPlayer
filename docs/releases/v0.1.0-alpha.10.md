# TrajPlayer v0.1.0-alpha.10

This prerelease turns TrajPlayer from a playback-focused viewer into an
interactive trajectory inspection tool. It adds picking, measurements, an
event-aware timeline, and a first set of scientific analyses while preserving
the alpha.9 molecular image, OpenGL renderer, bounded streaming cache, and
sequential no-skip playback.

## Picking, Selection, And Measurement

- Click an atom to replace the selection. Shift-click adds, Ctrl-click on
  Windows/Linux or Cmd-click on macOS toggles, Alt-click removes, Esc clears,
  and F focuses the selected atoms.
- Picking uses a GPU atom-ID pass with canonical atom indices. Drivers that
  reject the preferred integer framebuffer fall back to RGBA8 IDs and then a
  chunked NumPy ray/sphere test.
- Selecting two, three, or four atoms produces a distance, angle, or dihedral.
  Measurements can be pinned in the viewport and analyzed over time.
- Minimum-image geometry uses fractional coordinates and supports triclinic
  periodic cells.

## Timeline And Analysis

- The timeline supports event markers, an optional playback range, preview and
  analysis cursors, double-click marker creation, and direct marker seek.
- Added density over time, density-profile heatmaps, MSD from the origin,
  time-averaged MSD, RMSD, RMSF, center of mass, radius of gyration, and pinned
  measurement time series.
- Analysis runs in one cancellable background scan with a reusable frame slab.
  Playback and live timeline scrubbing take priority over uncached analysis I/O.
- Time-averaged MSD uses a disk-backed float32 temporary store, then selects a
  direct or NumPy FFT calculation without retaining the trajectory in RAM.
- The built-in plot supports lines, multiple series, heatmaps, linear/log axes,
  rubber-band zoom, tooltips, exact frame seek, CSV export, and PNG export.
  Its static data layer is cached so a 60 FPS timeline cursor does not rebuild a
  large curve or heatmap every frame.

## Desktop Workflow

- Added Light, Dark, and Follow System themes. New installations retain the
  existing white Light theme by default.
- Added runtime Qt `.qm` translations for Chinese and English.
- Added a recent-trajectory menu that keeps GRO plus XTC/TRR as one source, and
  drag feedback for supported, incomplete Gromacs, and unsupported drops.
- Current coordinates can be exported as XYZ/extXYZ. The viewport and analysis
  plot can be saved as PNG, and complete analysis arrays can be saved as CSV.
- Added Shift+Left/Right for ten-frame steps, Ctrl/Cmd+L for the analysis pane,
  Ctrl/Cmd+Shift+O for recent files, and Delete for the active pinned item when
  the viewport has focus.

## Measured Performance

On one Windows 11 system with an NVIDIA GeForce RTX 4070 Laptop GPU and OpenGL
3.3, the alpha.10 source build measured:

| Scenario | Result |
| --- | ---: |
| 100,000 atoms + 99,999 bonds | 60.00 FPS |
| 100,000 atom paint p95 | 2.83 ms |
| 100,000 atom position upload p95 | 0.39 ms |
| 1,000,000 atom paint p95 while rotating | 6.41 ms |
| 1,000,000 atom first frame after rotation stops | 23.02 ms |
| 1,000,000 atom GPU picking p95 | 5.37 ms |

The tests reported zero skipped or duplicated trajectory frames and zero
renderer-side full-frame CPU copies. These are local reference measurements,
not hardware-independent guarantees.

## Scientific Boundaries

- TrajPlayer does not invent physical time. Curves use frame number unless the
  user supplies a frame interval and unit.
- Periodic MSD needs continuous no-jump coordinates. TrajPlayer can unwrap from
  consecutive fractional coordinates when every frame has a valid cell, but
  users should validate unusual changing-cell trajectories against their
  simulation workflow.
- No diffusion coefficient is reported automatically. Choosing a physically
  meaningful linear lag interval and finite-size treatment remains the user's
  responsibility.
- PBC make-whole for COM, Rg, RMSD, and RMSF is anchor-relative and is most
  meaningful for one connected molecule or selection. A disconnected whole
  system may need domain-specific grouping first.
- This alpha does not provide statistical error estimates, molecular surfaces,
  ribbon representations, publication rendering, or a scripting API.

See [Scientific Analysis](../analysis.md) for definitions and references.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.10.zip` from the assets below,
not the source archive under **Code > Download ZIP**. Extract the complete
archive and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required.
Keep `_internal` beside the executable; do not send the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.10.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and the common Qt XCB runtime
libraries listed in the README are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.10.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.10.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

Use **Open** or drag files into TrajPlayer. ASE `.traj`, `.xyz`, and `.extxyz`
open directly. GRO and XTC/TRR can be selected or dropped together; a
same-named GRO beside XTC/TRR is detected automatically. Keep original
trajectories and report reproducible issues through GitHub Issues.
