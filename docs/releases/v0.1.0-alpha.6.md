# TrajPlayer v0.1.0-alpha.6

This prerelease restructures the frame, reader, rendering-scheduler, UI, and
topology hot paths while preserving the existing molecular appearance and
sequential no-skip playback behavior.

## Performance And Responsiveness

- Frame leases let OpenGL upload the streamer's contiguous float32 frame
  directly, removing a renderer-side full-frame CPU copy.
- Playback uses a one-frame present queue acknowledged by `frameSwapped`; it no
  longer performs synchronous `repaint()` calls on the UI thread.
- Camera depth sorting is deferred until pointer interaction is idle.
- The RAM frame cache now uses an adaptive 64-256 MiB unified memory budget and
  reports cache-hit, decode-latency, throughput, and effective-prefetch data.
- Native `trajcore` cell-list and union-find routines accelerate bond inference,
  with a SciPy-free NumPy fallback.

## Opening Trajectories

- ASE `.traj`, extXYZ, GRO, PDB, CIF, XTC, and TRR now use direct readers. A
  full decoded float32 sidecar is no longer required.
- Large XYZ/extXYZ files show their first frame before a progressive byte-offset
  index finishes in the background.
- XTC/TRR decoding uses Chemfiles instead of MDAnalysis.
- Source and packaged release jobs exercise every supported reader, while Linux
  and macOS also validate two real rendered OpenGL frames.

Use **Open** or drag files into TrajPlayer. Select or drag a GRO topology and
its XTC/TRR trajectory together; a same-named GRO beside XTC/TRR is also found
automatically.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.6.zip` from the assets below, not
the source archive under **Code > Download ZIP**. Extract the complete archive
and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required. Keep
`_internal` beside the executable and do not share the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.6.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and common Qt XCB runtime
libraries are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.6.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.6.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

This remains an alpha release. Keep original trajectories and report
reproducible issues through GitHub Issues.
