# TrajPlayer v0.1.0-alpha.3

This prerelease improves portable-package startup diagnostics without changing
TrajPlayer's UI, rendering quality, or playback behavior.

## Fixed

- Bundled NumPy and SciPy DLL directories are configured before NumPy is imported.
- An incomplete extraction or quarantined NumPy extension now produces an actionable
  startup message instead of the misleading NumPy source-directory traceback.
- Release builds validate the Python and NumPy native runtime files, then launch the
  final packaged application in a startup smoke test on Windows and Linux.
- Optional UPX packing is disabled to reduce interference from endpoint security
  software.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.3.zip` from the assets below, not
the source archive under **Code > Download ZIP**. Extract the complete archive
and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required. Keep
`_internal` beside the executable; do not run the EXE inside the ZIP or share it
by itself.

If a NumPy startup error remains, verify that
`TrajPlayer\_internal\numpy\_core\_multiarray_umath.cp310-win_amd64.pyd` exists
and check **Windows Security > Protection history** for quarantined files.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.3.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. The portable build requires Linux x86_64, OpenGL 3.3,
and common Qt XCB runtime libraries.

## Opening Trajectories

Use **Open** or drag files into the application. ASE `.traj`, `.xyz`, and
`.extxyz` files open directly. For Gromacs, select or drag a GRO topology
together with its XTC/TRR trajectory. TrajPlayer can also try a same-named GRO
beside an XTC/TRR file when the trajectory is opened by itself.

This is an alpha release. Cache metadata and file compatibility may change;
keep original trajectories and report reproducible failures through GitHub
Issues.
