# TrajPlayer v0.1.0-alpha.14

This prerelease hardens local trajectory parsing, decoded-cache handling, and
the GitHub release pipeline. It does not change the UI, molecular rendering,
camera, playback scheduling, analysis results, or export appearance.

## Data Safety And Reliability

- TrajPlayer refuses symbolic-link, Windows junction, and reparse-point cache
  directories before replacing a decoded cache, preventing a linked cache from
  redirecting recursive deletion outside its own sidecar directory.
- Cache identities now include a SHA-256 sample of the first and last 4 MiB of
  each source file in addition to path, size, and nanosecond timestamp. A
  same-size source rewrite can no longer silently display stale cached data.
- XYZ and GRO atom counts are checked against available file bytes before large
  NumPy arrays are allocated. ASE ULM JSON metadata is capped at 4 MiB.
- Python and native readers reject NaN or infinite coordinates and atomic
  numbers outside `0..118` before data reaches camera, sorting, or rendering.
- Malformed GRO box records now report a clear three-or-nine-value requirement,
  and cache permission failures remain permission failures instead of being
  mistaken for corrupt cache data.

## Release Integrity

- GitHub Actions are pinned to immutable commits and monitored by Dependabot.
- Build jobs have read-only repository access; only the publish job receives the
  permissions required to create a Release and signed provenance attestations.
- The four portable archives receive GitHub build-provenance attestations.
  Performance and bundle-size reports remain downloadable from the workflow run
  but are no longer mixed into the end-user Release assets.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.14.zip` from the assets below,
not the source archive under **Code > Download ZIP**. Extract the complete
archive and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required.
Keep `_internal` beside the executable; do not send the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.14.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and the common Qt XCB runtime
libraries listed in the README are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.14.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.14.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

Use **Open** or drag files into TrajPlayer. ASE `.traj`, `.xyz`, and `.extxyz`
open directly. GRO and XTC/TRR can be selected or dropped together; a
same-named GRO beside XTC/TRR is detected automatically.
