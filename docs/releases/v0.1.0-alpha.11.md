# TrajPlayer v0.1.0-alpha.11

This prerelease refines the alpha.10 scientific-analysis workflow without
changing molecular rendering, playback scheduling, or trajectory streaming.

## Analysis Scope

- Density over time and density-profile heatmaps now always use every atom in
  the system. A viewport selection cannot silently change the reported system
  density.
- Other selection-capable analyses default to **Entire system** and retain an
  explicit **Current selection** option for focused measurements.
- The scope control and tooltip state the active behavior in Chinese and
  English.

## Inspector Layout

- The responsive Inspector is divided into **View**, **Inspect**, and
  **Analysis** tabs.
- Analysis parameters and Run/Cancel actions now fit at the supported minimum
  window height, with an independent scroll area available when the desktop is
  smaller or display scaling is higher.
- Existing display controls, selection tools, timeline controls, rendering,
  and sequential no-skip playback behavior are unchanged.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.11.zip` from the assets below,
not the source archive under **Code > Download ZIP**. Extract the complete
archive and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required.
Keep `_internal` beside the executable; do not send the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.11.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and the common Qt XCB runtime
libraries listed in the README are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.11.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.11.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

Use **Open** or drag files into TrajPlayer. ASE `.traj`, `.xyz`, and `.extxyz`
open directly. GRO and XTC/TRR can be selected or dropped together; a
same-named GRO beside XTC/TRR is detected automatically.
