# TrajPlayer v0.1.0-alpha.7

This prerelease focuses on predictable latency, bounded memory, resumable
indexing, and portable-package validation. It preserves the alpha.6 UI,
molecular appearance, and sequential no-skip playback behavior.

## Streaming And Playback

- A generation-safe `PresentScheduler` owns target, displayed, and pending
  frame state and advances playback only after `frameSwapped`.
- Read-only, epoch-checked frame leases keep renderer uploads zero-copy while
  preventing a cache slot from being reclaimed too early.
- The frame cache now allocates 16 MiB slabs on demand and can grow or shrink
  under a hysteretic, cgroup-aware memory policy.
- Render and playback telemetry uses fixed-size NumPy rings, so diagnostics do
  not grow with trajectory length.

## Large XYZ And Large Scenes

- Progressive XYZ/extXYZ indexing gives foreground frame reads priority over
  background scanning, batches flushes, and resumes from atomic checkpoints.
- A 256-bin coarse depth order bounds million-atom post-input sorting latency;
  the existing sphere and bond shaders and display parameters are unchanged.
- Fresh multi-frame XYZ files are now handled deterministically by packaged
  OpenGL smoke tests while their index is still being created.

## Validation And Packaging

- Benchmark JSON now records startup/open latency, render/upload/present/read
  p50/p95/p99, RSS, cache/lease state, and actual renderer fallback-copy bytes.
- Correctness gates reject dropped or duplicate trajectory frames, stale
  leases, complete-frame CPU copies, and forbidden SciPy/MDAnalysis payloads.
- Bundle reports include largest files, dynamic libraries, SHA-256 duplicates,
  dependency-group deltas, and a two-percent unexplained-growth limit.
- Unused Qt QML/Quick, PDF, SVG, Virtual Keyboard, Network modules and plugins
  are excluded. The Windows portable directory measured 125.61 MiB in CI,
  about 21% smaller than the alpha.6 baseline.

On the reference RTX 4070 Laptop test, 100,000 atoms plus 99,999 bonds retained
about 60 FPS with zero dropped frames, zero duplicate presentations, and zero
renderer full-frame CPU copies. Hardware and driver results will vary.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.7.zip` from the assets below, not
the source archive under **Code > Download ZIP**. Extract the complete archive
and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required. Keep
`_internal` beside the executable and do not share the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.7.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and common Qt XCB runtime
libraries are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.7.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.7.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

Use **Open** or drag files into TrajPlayer. GRO and XTC/TRR can be selected or
dropped together; a same-named GRO beside XTC/TRR is detected automatically.
This remains an alpha release, so keep original trajectories and report
reproducible issues through GitHub Issues.
