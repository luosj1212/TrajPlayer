# TrajPlayer v0.1.0-alpha.13

This prerelease fixes element inference for atom labels that contain indices or
suffixes. It does not change the UI, molecular rendering, playback scheduling,
trajectory loading architecture, analysis, or export appearance.

## Element Recognition

- Labels now use their first contiguous letter run instead of joining letters
  across digits or punctuation. For example, `C00l` is carbon rather than
  chlorine.
- Genuine one- and two-letter species remain supported: `C`, `Cl`, and `Cl1`
  resolve to carbon, chlorine, and chlorine respectively.
- Python metadata parsing and the native memory-mapped XYZ/extXYZ parser use
  the same rule, so atom identity remains stable after the first frame.
- PDB names with a leading numeric position marker, such as `1HG1`, fall back
  to the one-letter element when the explicit element field is absent.

## Windows

Download `TrajPlayer-Windows-x64-v0.1.0-alpha.13.zip` from the assets below,
not the source archive under **Code > Download ZIP**. Extract the complete
archive and run `TrajPlayer\TrajPlayer.exe`. Python and Conda are not required.
Keep `_internal` beside the executable; do not send the EXE by itself.

## Linux

Download and completely extract
`TrajPlayer-Linux-x86_64-v0.1.0-alpha.13.tar.gz`, then run:

```bash
chmod +x TrajPlayer/TrajPlayer
./TrajPlayer/TrajPlayer
```

Python is not required. Linux x86_64, OpenGL 3.3, and the common Qt XCB runtime
libraries listed in the README are required.

## macOS

Download `TrajPlayer-macOS-arm64-v0.1.0-alpha.13.zip` for Apple Silicon or
`TrajPlayer-macOS-x86_64-v0.1.0-alpha.13.zip` for Intel. Extract the archive and
open `TrajPlayer-macOS/TrajPlayer.app`. Python is not required.

The app is ad-hoc signed but not Apple-notarized. On first launch, Control-click
the app, choose **Open**, and confirm. macOS 13 or newer and OpenGL 3.3 are
required.

Use **Open** or drag files into TrajPlayer. ASE `.traj`, `.xyz`, and `.extxyz`
open directly. GRO and XTC/TRR can be selected or dropped together; a
same-named GRO beside XTC/TRR is detected automatically.
